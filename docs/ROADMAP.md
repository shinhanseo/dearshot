# 8주 MVP 로드맵

## 1주차 — 기반

- Android 프로젝트와 디자인 토큰 적용
- CameraX 프리뷰, 권한, 전·후면 전환
- Node API와 앱의 개발 환경 연결

## 2주차 — 촬영

- 초점, 줌, 플래시, 이미지 캡처
- 앱 전용 임시 저장과 촬영 세션 모델
- 프로세스 종료 후 세션 복구

## 3주차 — 장면 분석

- 분석 프레임 리사이즈·회전·업로드
- 분석 로딩, 실패, 직접 장소 선택
- AI 출력 스키마 검증과 템플릿 ID 매핑

## 4주차 — 템플릿

- 원격 템플릿 카탈로그와 Room 캐시
- 장소별 목록, 상세, 즐겨찾기
- 오버레이 ON/OFF와 예시 확대

## 5주차 — 촬영 피드백

- 템플릿 기준 사진 분석
- 한 가지 핵심 피드백 화면
- 다시 찍기와 다음 구도 분기

## 6주차 — 세션과 저장

- 촬영 사진 비교·선택
- MediaStore 저장과 실패 복구
- 세션 종료, 임시 파일 정리

## 7주차 — 품질

- 한국어·영어와 접근성 점검
- 느린 네트워크·오프라인·회전·백그라운드 복구
- API 비용, 지연 시간, 이미지 크기 측정

## 8주차 — 출시와 포트폴리오

- 내부 테스트 및 비공개 테스트 배포
- 개인정보처리방침과 스토어 등록 정보
- 아키텍처·의사결정·트러블슈팅 README 정리
- 실제 기기 데모 영상과 성능 수치 기록
