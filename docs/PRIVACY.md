# 개인정보와 센서 권한

## 기본 원칙

- 카메라는 사용자가 촬영 화면을 보고 있을 때만 사용한다.
- 서버 분석은 일정 간격으로 선택한 프레임만 전송하고 영상을 지속 전송하지 않는다.
- 위치 없이도 사용할 수 있게 하고, 위치는 추천 정확도를 높이는 선택 권한으로 둔다.
- 촬영 사진은 앱 전용 저장소에 먼저 보관하며 사용자가 선택한 항목만 갤러리에 저장한다.
- 외부 AI 전송 전 무엇을 보내고 얼마나 보관하는지 설명한다.
- Android는 EXIF 위치를 제거하고 긴 변 2048px 이하로 압축한 분석 사본만 Node API에 multipart로 전송한다.
- 서버의 분석용 이미지는 작업 완료 후 즉시 삭제를 시도하고 장애 상황에서도 최대 1시간 안에 삭제한다.
- 업로드 응답과 로그에는 EC2 내부 파일 경로나 접근 가능한 이미지 URL을 포함하지 않는다.
- Google ID Token과 nonce 원문은 저장하거나 로그에 남기지 않는다. 계정 연결에는 Google의 안정적인 `sub`만 사용하고 nonce는 SHA-256 해시를 토큰 만료 시각까지만 보관한다.
- Kakao Access Token과 공급자의 원본 오류 응답은 저장하거나 로그에 남기지 않는다. 계정 연결에는 DearShot Kakao 앱의 토큰으로 검증된 회원번호만 사용한다.

## 서버 보존 기간

| 데이터 | 기본 보존 | 정리 방식 |
|---|---:|---|
| 분석·피드백 이미지 | 작업 종료 직후, 최대 1시간 | 파일 삭제 실패·프로세스 중단을 retention worker가 보정 |
| 위치·온디바이스 분석 힌트 | 작업의 최종 상태 전이 직후 | 결과를 남기기 전에 DB 컬럼을 null로 변경 |
| 장면 분석·피드백 결과 | 7일 | 만료 시 관련 작업 행 삭제 |
| AI 호출 audit | 30일 | provider, model, latency, token 수, 표준 오류만 보관 |
| 제품 사용 이벤트 | 90일 | 만료 시 원본 이벤트 삭제 |
| 멱등·OAuth nonce 기록 | 각 레코드의 만료 시각까지 | 주기 worker가 삭제 |

AI audit에는 이미지, 위치, 온디바이스 힌트, 원본 prompt와 provider 원본 응답을 저장하지 않는다.

## 회원 탈퇴

`DELETE /me`를 받으면 계정을 즉시 `DELETION_PENDING`으로 바꾸고 Refresh Token을 모두 폐기하며 진행 중인 AI 작업을 취소한다. 삭제 worker는 사용자 파일을 먼저 격리하고 DB transaction으로 계정 데이터를 지운 뒤 격리 파일을 확정 삭제한다. 파일 또는 DB 삭제가 실패하면 파일을 원위치로 복구하고 지수 backoff로 재시도하므로 DB만 지워지고 파일이 남는 상태를 만들지 않는다. 완료 상태는 7일 뒤 제거한다.

## 권한 요청 시점

| 권한 | 요청 시점 | 거부 시 동작 |
|---|---|---|
| 카메라 | 첫 촬영 진입 | 권한 설명과 설정 이동 제공 |
| 대략적 위치 | 장면 추천 정확도 향상 선택 시 | 이미지와 시간만으로 분석 |
| 알림 | 백그라운드 분석 완료 알림을 켤 때 | 앱 안에서만 완료 상태 표시 |

Android 10 이상에서는 MediaStore를 사용해 앱이 생성한 사진을 저장하므로 전체 사진 접근 권한을 요구하지 않는다.

## 출시 전 확정할 사항

- 사용하는 AI 제공자와 처리 국가
- 원본·리사이즈 이미지 보관 기간
- 계정·분석 기록 삭제 절차
- 얼굴이 포함된 이미지 처리와 미성년자 정책
- 개인정보처리방침 영문·국문 문서 및 문의 채널
