# 제품 요구사항

## 제품 한 문장

DearShot은 장면을 읽고 현재 장소에 어울리는 구도와 촬영 피드백을 안내하는 Android 카메라 앱이다.

## 해결하려는 문제

사용자는 여행지나 데이트 장소에서 사진을 많이 찍지만, 무엇을 어떻게 바꿔야 좋아지는지 알기 어렵다. 참고 사진을 찾더라도 현재 배경·인원·빛에 맞는지 판단하기 어렵고, 촬영 직후에는 “별로야”라는 감상만 남기 쉽다.

## 목표 사용자

- 연인·친구·가족의 인물 사진을 자주 찍어주는 사람
- 여행지에서 장소의 특징이 담긴 사진을 남기고 싶은 사람
- 사진 이론 없이도 다음 행동이 분명한 안내를 원하는 사람

## MVP 핵심 루프

1. 앱 진입과 카메라 권한 확인
2. 프리뷰 프레임과 시간·선택적 위치 문맥으로 장면 분석
3. 추천 근거와 촬영 템플릿 3개 제시
4. 템플릿 선택 후 구도·포즈 가이드 표시
5. 촬영 후 실행 가능한 피드백 한 가지 제공
6. 다시 찍기 또는 다음 구도 선택
7. 세션 사진 비교 후 선택 항목만 갤러리에 저장

## MVP 포함

- CameraX 프리뷰·초점·줌·플래시·촬영
- 장면 분석의 진행·완료·실패·직접 선택 상태
- 원격 구성 가능한 장소·템플릿 카탈로그
- 템플릿 예시, 오버레이 표시, 안내 문장
- 앱 전용 임시 저장소와 촬영 세션 복구
- 촬영 결과 피드백과 재촬영
- 선택 사진 MediaStore 저장
- 한국어·영어, 게스트 이용

## MVP 제외

- 생성형 후보정
- 실시간 영상 전체를 서버로 전송하는 기능
- 소셜 피드·팔로우·댓글
- 복수 사용자 공동 앨범
- 정밀 위치를 필수로 요구하는 기능
- 모든 장소를 포괄하는 템플릿 대량 구축

## 성공 기준

- 첫 실행 사용자가 설명 없이 장면 분석부터 첫 촬영까지 완료한다.
- 분석 실패 시 직접 장소를 고르고 촬영을 계속할 수 있다.
- 피드백이 “다시 찍기”라는 다음 행동으로 연결된다.
- 사용자가 촬영 세션에서 최소 한 장을 갤러리에 저장한다.
- 앱 종료·프로세스 중단 뒤에도 미완료 세션을 복구한다.
